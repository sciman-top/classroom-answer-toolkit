# 指针式电流表独立视觉审计

所附图片是原始试卷的局部裁图，不是参考答案。请独立读取电流表，禁止根据常见题型猜量程。

必须严格按以下顺序输出：

1. 逐个检查表盘下方 `-`、`0.6`、`3` 三个接线柱，描述每个接线柱下方是否画有向外延伸的黑色导线。只有实际连接导线的两个端子决定量程。
2. 根据所连接的正接线柱，在 `0-0.6 A` 与 `0-3 A` 中选择量程；明确说明另一排数字不得使用。
3. 对所选数字刻度，数出 0 到第一个标数字之间分成多少个“小格间隔”，计算每小格数值。零刻线只是边界，不是第一个小格；不得把刻线条数当成间隔数。
4. 从 0 起数到红色指针对应位置跨过多少个刻线间隔，分别按上下两排刻度计算读数，并核对两排读数是否恰为 5 倍关系。
5. 最后给出唯一读数。若某条导线或刻度确实无法辨认，写“无法可靠判读”，不得猜测。
