# Historical Strategy Plans

本目录保存已经冻结、被替代或随产品简化退出当前执行链的历史计划。文件保留用于决策追溯，
不代表当前产品范围、架构承诺、待办任务或恢复已删除模块的授权。

## 执行边界

- 当前策略真源只看 [`docs/strategy/README.md`](../../strategy/README.md) 列出的文件。
- 当前任务真源只看 [`execution-backlog.md`](../../strategy/execution-backlog.md)。
- 本目录中的 `todo`、`next`、阶段状态、完成定义和旧模块路径全部视为 historical evidence。
- AI 不得根据本目录创建任务、修改生产 spec、恢复 visual/synthetic/review/flywheel 工具链或扩大门禁。
- 若历史能力重新获得真实需求，必须先在 current PRD 中确认范围，再建立带依赖、write set、验证和停止条件的 `status: ready` backlog 条目。

## 归档范围

本次归档共 29 份计划，覆盖以下已退出当前阅读链的主题：

- DOCX page normalization、Typst primary renderer；

- visual preprocessing、observation、diagnostics、association、semantics、projection、structure、scale 与 machine review。

归档迁移不改变历史正文；链接修复仅用于保持追溯可读性。
