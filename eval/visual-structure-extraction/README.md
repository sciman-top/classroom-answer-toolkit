# Visual Structure Extraction Eval

`cases/` contains one public `synthetic_fixture` request/result pair for each
subject pack. Each request binds the committed VISION-007 preprocessing result
and its scale=2 crop. Each expected result records deterministic, nonsemantic
line, connected-region, and heuristic-only text-region candidates.

These artifacts prove only local pixel-structure extraction and replay. They
contain no recognized text and do not represent axis/tick/component semantics,
`FigureUnderstandingResult`, Track B evidence, real paper quality, gateway
integration, workflow integration, or live acceptance.
