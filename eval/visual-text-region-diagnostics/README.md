# Visual Text-region Diagnostics

This evaluation surface contains one inventory and one deterministic report
compiled from the committed VISION-008 heuristic text-region candidates and
VISION-011 generator-declared synthetic truth.

Only positive-area overlap with fully visible truth is scored. Candidate
overlap with partially clipped truth is unscored, and outside-crop truth does
not shield candidates. The metrics apply only to these three public synthetic
fixtures; they are not recognized text, an OCR-region association, a real
region benchmark, layout semantics, FigureUnderstanding, Track B, workflow
integration, or live acceptance.
