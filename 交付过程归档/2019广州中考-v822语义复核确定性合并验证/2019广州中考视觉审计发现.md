# 视觉审计发现报告

> 本报告只核对原图可直接观察的字段。  
> “未见不一致”不代表已经完成第二次物理作答。

## 一、选择题逐题审计

1. 【未见直接视觉不一致】表中甲为 \(70\,\mathrm{dB}\)、\(1100\,\mathrm{Hz}\)，乙为 \(110\,\mathrm{dB}\)、\(700\,\mathrm{Hz}\)。候选 D 依赖的数据与表格一致。

2. 【语义复算分歧，仅供参考复核】候选 D 包含“电子”；原题选项 C 为“质子和中子”。原子核组成需按教材知识复算，结果指向 C。

3. 【未见直接视觉不一致】图2显示小轮在支架上往返、断电后逐渐停止。候选 D 不与图中可见运动状态矛盾。

4. 【未见直接视觉不一致】本题没有独立视觉量可直接判定候选 D，需依靠内能、扩散概念复算。

5. 【未见直接视觉不一致】图3中 \(a\) 点位置最高、距水面最近。候选 A 依赖的几何位置与原图一致。

6. 【未见直接视觉不一致】图中磁感线均水平向左；D 中导线垂直纸面、运动方向向下。是否产生感应电流仍属语义复算。

7. 【语义复算分歧，仅供参考复核】候选 B 表示液体体积持续减小到零。温度计先在约 \(26^\circ\mathrm{C}\) 环境中，放入冰水混合物后先降温；时间足够长时冰融化，水又受环境加热。复算结果指向“下降、保持、再上升”的 A。

8. 【语义复算分歧，仅供参考复核】图6直接可见小球位于杆的北侧。由惯性判断装置运动方向需语义复算，结果指向南，即 B；候选为 C（西）。

9. 【未见直接视觉不一致】图7中 AB 与 CD 的竖直高度均为 \(H\)，候选 A 所用几何关系未见视觉矛盾。

10. 【语义复算一致，仅供参考复核】候选 B 的完整向量绑定如下：  
   - 目标导体电流：\(\odot\)，从纸后进入、由纸面向外离开；  
   - 左电磁铁朝向间隙的一端为 S，右电磁铁朝向间隙的一端为 N；  
   - 间隙磁场按 N→S，为从右向左；  
   - 图8校准关系为“电流入纸面、磁场向右、受力向下”；  
   - B 中电流与磁场同时反向，受力仍向下。候选 B 未见矢量绑定矛盾。

11. 【未见直接视觉不一致】题干明确写出甲、乙排开液体的重力相等；候选 C 需要再结合浮力规律判断，不属于单纯视觉结论。

12. 【直接视觉不一致】候选 D 中“\(U\) 不变”与图11、图12的电压表读数直接矛盾。  
   - 图11电压表证据链：目标图11；显示接线柱；接“−、3”；量程 \(0\sim3\,\mathrm{V}\)；内圈刻度；分度值 \(0.1\,\mathrm{V}\)；指针位于 1 与 2 的中点；双向读数均为 \(1.5\,\mathrm{V}\)。  
   - 图12电压表证据链：目标图12；显示接线柱；接“−、3”；量程 \(0\sim3\,\mathrm{V}\)；内圈刻度；分度值 \(0.1\,\mathrm{V}\)；指针位于 2 与 3 的中点；双向读数均为 \(2.5\,\mathrm{V}\)。  
   - 原图直接结论：\(U\) 变大。  
   - 图中电流表读的是干路总电流，不能直接替代题目所指的定值电阻支路电流 \(I\)。按 \(I=U/R\) 复算，固定 \(R\) 时 \(I\) 也变大，对应 A；这部分属于语义复算。

## 三、审计结论

直接视觉层面确定的问题为第12题电压表变化判断。另有第2、7、8题存在语义复算分歧；这些不是单纯视觉事实修正。其余已审计的图号、刻度、方向、端子和连接拓扑未发现候选与原图直接矛盾。
