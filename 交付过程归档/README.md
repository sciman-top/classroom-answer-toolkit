# 交付过程归档

本目录保存正式交付整理前的生成与复核过程材料，仅用于追溯，不作为面向使用者的正式交付入口。

正式交付入口：`正式交付/广州中考物理/<年份>/<年份>广州中考物理参考答案.pdf`。

同年正式 PDF 的选取规则：

- 2025：选择带教师 `accepted` 记录的 `2025广州中考-original-三档复跑`。
- 2019：选择成功完成语义合并的 `2019广州中考-v822语义复核确定性合并验证`。
- 其他年份：选择整理时对应年份的当前盲答闭环或待复核主链目录。

归档中的候选稿、复核报告、manifest、snapshot、workflow receipt、review 图片和旧复跑结果均不是额外正式交付物。
