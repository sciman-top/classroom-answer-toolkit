# 试卷参考答案交付规范-图文定量题通用 v1.1

> 适用范围：适用于多数学科中的图像、表格、坐标图、仪表、实验图、结构图、定量读图题。
> 文件角色：承载跨学科图文定量题的共性约束。

## 1. 图文证据优先

1. 题目若要求“根据图”“由表可知”“读数可得”，必须先抽取图文证据，再进入求解。
2. 同一道题有多幅图或多组数据时，必须先完成“小问 -> 图号/数据源”绑定，不得跨图误答。
3. 计算只作一致性校验，不得替代应由图表直接读出的答案。
4. 高风险视觉题不得只凭整页缩略图下结论；应优先查看绑定题号的局部高清图，并保留原页上下文供回查。
5. 若当前链路只能得到 OCR 文本或整页截图，不能静默假装已完成看图；应按对应小问标【疑】/待复核。

## 2. 题目级视觉复核

1. 先确定题号、小问和对应图号或数据源，再查看局部图；不得让后续小问或相邻题目的图像结论污染当前答案。
2. 仪表题先追接线柱和量程，再确认分度值、相邻主刻度与指针位置；刻度尺分别读取起点和终点；滑轮逐段追绳；多个钩码逐个计数。
3. 局部高清图只用于提高有效像素占比，不自动消除指针、刻线、绳段或实例绑定歧义。
4. 视觉发现与候选答案冲突时，只有证据和计算链明确支持的修正才能写入最终答案；证据不足时保留可确定内容并标【疑】/待复核。
5. 最终输出只能是完整答案 Markdown，不输出内部检查表、JSON、证据对象、置信度对象或分析过程。

## 3. 仪表与刻度读数

1. 仪表读数必须明确读数对象、量程或零点/起点、分度值、相对位置和最终数值。
2. 若读数差异发生在最小分度级别，必须重新放大原图，从相邻主刻度两个方向复读。
3. 不得把阴影、外框、装饰线、黑块、游码整体宽度等非读数要素误当读数依据。

## 4. 视觉高风险分类

以下题型默认视为视觉高风险：

- 刻度/仪表读数题
- 几何关系或图像关系题
- 坐标图/函数图读图题
- 实验装置图与电路图
- 作图题
- 多图多问绑定题
- 模糊、倾斜、遮挡、低清晰度题图
- 题图与 OCR 冲突、题图与参考答案冲突

## 5. 候选、视觉审计与参考复核

1. 无参考答案生成的结果是待复核候选，不得写成官方答案或可信答案。
2. 只依据原卷图像执行的视觉审计不接触参考答案；审计完成不等于视觉正确性已经验收。
3. 提供权威参考答案时，应逐题比较并生成完整校正 Markdown，不得只输出差异摘要。
4. 候选、视觉审计和参考答案相互冲突、证据不足、绑定不稳或规则校验阻断时，不能静默放行。
5. 题图模糊、遮挡或读图不稳时，默认策略是先完成可确定部分，并在对应小问标【疑】/待复核；不是立即中断整题或整卷。
6. 只有当图像疑点会同时影响多个关键小问、无法建立最基本的图号绑定或量纲边界时，才暂停提问。

## 6. 较难题分析边界

1. 视觉题若只是看图读数出错，不默认展开成长分析。
2. 只有关系隐蔽、分段明显、阈值判断、图像综合统筹类小问，才属于应补充分析的较难题。
