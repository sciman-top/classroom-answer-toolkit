# Visual scale lattice

This deterministic public synthetic compiler binds an explicit scale-lattice declaration to the
current component-semantics and structure authorities. It derives a relative pointer subdivision
index using doubled-pixel integer geometry. It does not infer a physical quantity, unit, scale label,
answer, trust, workflow status, or live acceptance.

```powershell
npm --prefix tools/visual-scale-lattice test
npm --prefix tools/visual-scale-lattice run validate:fixtures
```
